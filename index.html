Zone assignment logic
When a client books, the system checks their suburb against each van's list. If the suburb matches Van 1, the job is assigned to Van 1. If it matches Van 2, it goes to Van 2. If no match, it defaults to Van 1. Changes here apply immediately to all new bookings.
